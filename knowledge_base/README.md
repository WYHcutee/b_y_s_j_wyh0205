# RAG 知识库说明

此文件夹用于存储 RAG (Retrieval-Augmented Generation) 知识库的相关文件。

## 目录结构

```
knowledge_base/
├── README.md           # 本说明文件
├── faiss_index/        # FAISS 向量索引目录（自动生成）
│   ├── index.faiss
│   └── index.pkl
└── documents/          # 原始文档目录（可选）
    └── *.txt
```

## 使用方式

1. 通过知识库管理页面 (http://127.0.0.1:5000/rag) 添加知识内容
2. 系统会自动将知识内容转换为向量并存储在 `faiss_index/` 目录中
3. 在进行网站检测时，系统会自动检索相关知识并显示在检测结果中

## 知识内容建议

建议添加以下类型的网络安全知识：

- 钓鱼网站的常见特征和识别方法
- 恶意网站的行为模式和危害
- 网络安全最佳实践
- 常见网络诈骗手段和防范措施
- 域名安全相关知识
- SSL/HTTPS 安全认证说明

## 注意事项

- `faiss_index/` 目录由系统自动管理，请勿手动修改
- 知识内容应尽量准确、权威
- 定期更新知识库内容以保持信息的时效性
